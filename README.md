# TP2_DL
Ce TP implémente des techniques avancées d'ingénierie telles que la régularisation L2, le Dropout et la Batch Normalization pour optimiser un modèle Deep Learning sur le jeu de données MNIST. Il intègre également un suivi systématique des performances via MLflow pour comparer l'efficacité des optimiseurs Adam, RMSprop et SGD avec Momentum.
